# cli-pretty-errors

A lightweight, zero-dependency Node.js library that transforms confusing error messages and long stack traces into clear, readable terminal output with actionable troubleshooting suggestions.

## Goals

- **Human-Readable Output**: Clean layout with visual hierarchy instead of noisy raw stack dumps.
- **Actionable Hints**: Helpful explanations and suggestions for common Node.js and JavaScript errors.
- **Comprehensive Support**: Handles native errors, system errors, nested/caused errors, and unexpected thrown values (strings, objects, null, undefined).
- **Lightweight & Modular**: Pure ES Modules with zero unnecessary dependencies.
